# TranslatorApp
WinForms-приложение для перевода текста через DeepL API с поддержкой выбора языка и сохранением истории переводов в SQLite базу данных. Разработать полноценное настольное приложение на языке C# (технология Windows Forms), демонстрирующее навыки проектирования интерфейсов, работы с базами данных, сетевыми протоколами и асинхронным программированием.

# Основные возможности:
- Поддержка автодетектора исходного языка (DeepL сам определяет язык текста).
- Выбор целевого языка из списка (Русский, Английский, Казахский, Немецкий, Японский).
- Сохранение переводов в локальную базу данных SQLite.
- Отображение статуса подключения к БД.
- Иинтеграция с DeepL API через TranslationService, где написана логика работы API-части.

− **Тип приложения:**

# Установка и запуск winForms приложения:
- Склонируйте репозиторий:
  ```bash
  git clone https://github.com/Shadow-product/Practice-Translator-App.git
- Перейдите в папку проекта через терминал: cd WindowsFormsApp1
- Откройте проект в Visual Studio.
- Настройте файлы у себя локально appSettings.config и connectionStrings.config.
- Откройте форму с двумя текстовыми полями, где хранится текущий и переводящий язык
- Заполняйте первое текстовое поле и во втором будет переводящий язык (переведенный)

## Настроить строку подключение работа Базы Данных и API-ключа:
- Пример файла в репозитории проекта connectionStrings.config.example (База Данных) и appSettings.config.example (API-ключ)
- Чтобы получить API-ключ нужно обратится команде разрабатываемая приложение winForms TranslatorApp автором проекта
- Запустить проект в Visual Studio.

## Использование приложение:
- Ввести текст в поле Source.
- Выбрать язык перевода в ComboBox.
- Нажать кнопку Перевести.
- Результат появится в поле Target и сохранится в базе данных.
