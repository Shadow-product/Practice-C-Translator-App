# TranslatorApp
WinForms-приложение для перевода текста через DeepL API с поддержкой выбора языка и сохранением истории переводов в SQLite.

# Основные возможности:
Поддержка автодетектора исходного языка (DeepL сам определяет язык текста).
Выбор целевого языка из списка (Русский, Английский, Казахский, Немецкий, Японский).
Сохранение переводов в локальную базу данных SQLite.
Отображение статуса подключения к БД.
Простая интеграция с DeepL API через TranslationService, где написана логика работы API-части.

# Требования
.NET Framework 4.8.
SQLite (локальная база). -
DeepL API Key (нужно получить ключ DeepL при разработке нового проекта).

# Установка и запуск 
Клонировать репозиторий (чтобы получить версию проекта):
git clone https://github.com/Shadow-product/Practice-Translator-App.git

## Настроить строку подключение работа Базы Данных и API-ключа:
Пример файла в репозитории проекта connectionStrings.config.example (База Данных) и appSettings.config.example (API-ключ)
Чтобы получить API-ключ нужно обратится команде разрабатываемая приложение winForms TranslatorApp автором проекта
Запустить проект в Visual Studio.

## Использование приложение:
Ввести текст в поле Source.
Выбрать язык перевода в ComboBox.
Нажать кнопку Перевести.
Результат появится в поле Target и сохранится в базе данных.

# Структура проекта
Data/DatabaseInitialize.cs - логика работы запуска winForms приложения
Forms/TranslatorApp.cs - основная форма приложения.
Models/Translation.cs - модель (объект) перевода.
Models/User.cs - модель (объект) пользователя.
Repositories/TranslationRepository.cs — сохранение переводов.
Repositories/UserRepository.cs — работа с пользователями.
Services/TranslationService.cs — работа с DeepL API.
